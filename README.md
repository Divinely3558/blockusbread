# BlockUSBRead

在 Docker 容器中解密并挂载 BitLocker USB 硬盘，通过网页管理、用 **SFTP 与内置文件浏览器** 读取文件。

单容器内置 FastAPI 管理后端与 OpenSSH sshd（internal-sftp）：网页负责解锁 / 挂载 / 浏览 / 安全弹出，挂载后的卷既可在网页内直接浏览、在线播放与上传，也通过 SFTP 共享给局域网内的电脑、手机播放器直接访问，可流畅播放视频等大文件。SFTP 会话被 Chroot 锁定在挂载根目录，无法浏览容器其他路径。

- **BitLocker**：支持用户密码与 48 位恢复密钥；dislocker 引擎优先，遇到新版元数据格式自动切换 cryptsetup
- **普通分区**：NTFS / exFAT / FAT32 / ext4
- **三类存储**：本地文件（宿主机目录映射进容器，始终可读写、不可弹出）、外接存储（USB 硬盘）、远程存储（SFTP 挂载远程硬盘，支持按组合并管理），三者可在网页内互相移动 / 复制文件
- **网页文件浏览**：目录浏览、视频 / 音频在线播放（支持拖动进度）、图片预览、文本在线查看、文件下载；读写卷额外支持上传、删除、重命名，并可把文件 / 文件夹在三类存储之间移动或复制（容器后台传输，可在顶栏查看进度 / 剩余时间 / 取消）
- **默认只读**，更安全；需要写入时可勾选读写模式（二次确认）
- **实时状态**：每个已挂载卷显示所在硬盘的真实读 / 写吞吐（↓ 读取 / ↑ 写入）与容量占用条；顶部面板可查看当前 SFTP 连接与正在传输的文件
- **可观测性**：支持 SMART 的硬盘显示健康状态、温度与通电时长
- **安全加固**：SSH 主机密钥持久化（指纹不变）、登录失败限流、经可选 HTTPS 反代访问时自动下发 Secure Cookie
- **热插拔**：插入自动识别、拔出自动清理，网页实时刷新（SSE），无变化时不刷新
- **记住此卷**（需配置 `SECRET_KEY`）：凭据加密后存入本地，手动解锁时免输密码（不自动挂载）
- **单端口管理 + SFTP 共享**：管理页 `8000`，SFTP 默认 `2222`（可改）；可选 HTTPS 入口 `8443`
- 移动友好的响应式网页界面

> 当前版本 **v1.1.0**。不支持 TPM 解锁、空闲自动锁定与多用户；HTTPS 为可选自签证书方案（见[文末](#可选-https局域网加密访问)）。

## 环境要求

- 已安装 Docker 与 Docker Compose（`docker compose` 插件）的 Linux 主机
- 容器以 `privileged` 运行并挂载 `/dev`，用于读取块设备、执行 mount 与 FUSE 挂载

## 快速开始

```bash
# 1. 进入项目目录
cd blockusbread

# 2. 创建环境配置文件
cp .env.example .env
# 编辑 .env：
#   ADMIN_PASSWORD=你的强密码
#   SECRET_KEY=$(openssl rand -base64 32)   # “记住此卷”加密密钥，必填

# 3. 构建并后台启动
docker compose up -d --build
```

启动后浏览器打开 `http://<宿主机IP>:8000`，用 `.env` 中的 `ADMIN_USER`（默认 `admin`）与 `ADMIN_PASSWORD` 登录。

常用命令：

```bash
docker compose logs -f          # 查看实时日志
docker compose restart          # 重启
docker compose down             # 停止（停止时自动卸载全部卷）
```

## 环境变量

在 `.env` 中配置：

| 变量             | 必填   | 默认    | 说明                                                                                                         |
| ---------------- | ------ | ------- | ------------------------------------------------------------------------------------------------------------ |
| `ADMIN_USER`     | 否     | `admin` | 管理员账号，网页登录与 SFTP 共用                                                                             |
| `ADMIN_PASSWORD` | **是** | —       | 管理员密码，网页与 SFTP 共用。修改后执行 `docker compose up -d` 重建容器即生效                               |
| `SECRET_KEY`     | **是** | —       | “记住此卷”凭据的加密密钥，`openssl rand -base64 32` 生成。**一旦使用请勿更换**，否则已保存凭据无法解密       |
| `LOG_LEVEL`      | 否     | `INFO`  | 日志级别，`INFO` / `DEBUG`                                                                                   |
| `SFTP_HOST_PORT` | 否     | `2222`  | SFTP 映射到宿主机的端口（容器内固定监听 22）。端口被占用时改为其他值                                         |
| `HTTPS_PORT`     | 否     | `8443`  | 可选 HTTPS 反代端口；需以 `--profile tls` 启动 Caddy 反代才生效，详见[可选 HTTPS](#可选-https局域网加密访问) |

> 账号密码以容器环境变量为唯一来源，不提供网页改密入口。改密码：编辑 `.env` 后 `docker compose up -d`。

## 使用流程

1. 将 USB 硬盘插入宿主机，网页磁盘列表会自动出现该盘（无需刷新）；支持 SMART 的硬盘会在磁盘卡片上显示健康、温度与通电信息（硬盘盒不支持透传时自动隐藏）。
2. BitLocker 卷：选择「用户密码」或「恢复密钥」，输入后点「解锁并挂载」。
   - 默认只读；勾选「以读写模式挂载」会弹出二次确认。
   - 勾选「记住此卷」（需配置 `SECRET_KEY`）后凭据加密保存：下次解锁无需再输密码，直接点「解锁并挂载」即可；已记住凭据的卷**不会自动挂载**，插入 / 重启后仍需手动点击解锁。
3. 普通分区（NTFS / exFAT / FAT32 / ext4）可直接挂载。
4. 挂载成功后，页面显示该卷的容量条、所在硬盘的实时读 / 写吞吐与「浏览文件」按钮；也可以通过 [SFTP](#访问-sftp) 访问文件。
5. 有人正在通过 SFTP 传输时，页面顶部出现会话面板，可展开查看“谁正在读取 / 写入哪个文件”；此时安全弹出会提示具体占用文件。
6. 用完先在各客户端断开连接，再到网页点「安全弹出」；直接物理拔出也会自动清理挂载状态。

不接 USB 盘也可以用：通过[三类存储](#三类存储)把宿主机目录或远程 SFTP 硬盘接入，网页与 SFTP 的使用方式与外接硬盘完全一致。

## 三类存储

页面存储区域从上到下固定为**本地存储 → 外接存储 → 远程存储**，没有对应存储的区域自动隐藏；三类存储之间可在网页内互相移动 / 复制文件。

**本地文件**（始终可读写、不可弹出）：编辑 `docker-compose.override.yml`（已被 `.gitignore` 忽略，不进仓库），把宿主机目录映射到 `/mnt/usb/local/<存储名>`：

```yaml
services:
  blockusbread:
    volumes:
      - /home/你的用户/资料:/mnt/usb/local/资料
      - /home/你的用户/照片:/mnt/usb/local/照片
```

支持多个映射：多个位置合并为一张「本地文件」卡片，每个位置一行，样式与 USB 多分区一致；修改后 `docker compose up -d` 重建容器生效。

**远程存储**（SFTP 挂载远程硬盘）：顶栏点「**挂载远程存储**」（需配置 `SECRET_KEY`，凭据加密后才落盘）。支持两种填法：

- **快速连接**：粘贴 `sftp://user@host:port/path`（或 `sftp://host:port/path`）自动填充下方字段，只需再输入密码；
- **逐项填写**：主机、端口、用户名、密码、远端路径。

「远程组」留空默认为用户名，可自定义；同一远程组的多个挂载合并显示在一张组卡片下（每个远端路径一行，类似 USB 多分区）。凭据使用 `SECRET_KEY` 加密保存到容器数据目录，重启容器自动重连；连接失败时该行稳定显示「连接失败」，可重连或删除，删除仅移除挂载配置、不动远端文件。

## 网页浏览文件

挂载任意卷后，在该卷一行点击「**浏览文件**」即可打开文件浏览器，无需另装 SFTP 客户端：

- **浏览与下载**：面包屑逐层进入目录，普通文件点击即下载。
- **在线播放 / 预览**：视频、音频在网页弹窗内直接播放，支持拖动进度（HTTP Range）；图片直接预览。
- **上传**（仅读写卷）：点「上传文件」选择本地文件，带进度条；同名文件会先询问是否覆盖。
- **删除 / 重命名**（仅读写卷）：每行文件右侧操作按钮；删除目录需自行先清空。
- **在线查看文本**：txt / log / json / md / yaml 及常见代码、配置等 40 余种纯文本类型（1 MiB 以内）点击直接在弹窗内查看；超过大小限制请下载后用编辑器打开。
- **移动 / 复制到其他卷**：文件或文件夹右侧点「移动」（仅读写卷）/「复制」（任意卷，只读卷也能复制出去），在弹窗选择目标位置（按本地 / 外接 / 远程存储分组）与目录后开始传输。任务在容器后台执行，关闭网页也会继续；同一时间只执行一个任务，涉及相同磁盘的后续任务自动排队，前一任务完成后立即开始。顶栏「传输任务」可查看排队状态与实时进度（百分比、已传大小、剩余时间、当前文件）并随时取消；移动被取消或失败时自动删除目标盘半成品，源文件保持不动。
- 只读卷只提供浏览 / 下载 / 播放，所有写操作按钮不显示。

> 浏览器内置播放器对编码有要求：H.264/AAC 的 MP4 兼容性最好；MKV、HEVC 等若无法播放，请改用 VLC 经 SFTP 访问。

## 访问 SFTP

SFTP 登录后根目录即挂载目录（容器内 `/mnt/usb`，已做 Chroot 隔离，看不到容器底层文件）。挂载后的卷路径：外接存储为 `<磁盘ID>/part<序号>/fs`，本地存储为 `local/<存储名>`，远程存储为 `remote/<组名>/<路径名>`。
账号密码与网页登录相同，页面顶部信息条可一键复制连接地址、账号与密码（密码仅显示圆点）；每个卷信息中的 **SFTP 路径条**（`sftp://…` 圆角条）点击即可复制该卷的完整路径。

**图形客户端（推荐）**：WinSCP、FileZilla、Cyberduck 等

- 协议：`SFTP`，主机：`<宿主机IP>`，端口：`2222`（改过则用新端口）
- 登录后进入 `<磁盘ID>/part<序号>/fs` 即为该分区文件

**命令行**

```bash
# 交互式登录后用 cd / ls / get / put 操作
sftp -P 2222 admin@<宿主机IP>

# 直接下载 / 上传单个文件
scp -P 2222 admin@<宿主机IP>:'FC30383E5705D/part1/fs/视频.mp4' ./
scp -P 2222 ./视频.mp4 admin@<宿主机IP>:'FC30383E5705D/part1/fs/'
```

Linux 图形文件管理器（Nautilus / Dolphin 等）地址栏：`sftp://admin@<宿主机IP>:2222/`

**macOS**：Finder → 前往 → 连接服务器，输入 `sftp://admin@<宿主机IP>:2222`（macOS 访达对 SFTP 写入支持有限，建议用 Cyberduck / FileZilla）

**手机 / VLC 等播放器**：新建 SFTP 连接，主机 `<宿主机IP>`、端口 `2222`、用户名 `admin`，浏览到对应卷的 `part<序号>/fs` 目录播放

> 说明：SFTP 仅允许文件传输，禁止交互式 Shell 登录与端口转发。

## 可选 HTTPS（局域网加密访问）

默认管理页为明文 HTTP，适合可信局域网。需要加密（例如在不可信网络中访问）时，可启用内置的 Caddy 反向代理，使用**自签证书**提供 HTTPS（无需域名、不依赖外部 CA）：

```bash
docker compose --profile tls up -d
```

然后访问 `https://<宿主机IP>:8443` 。浏览器首次会提示“证书不受信任”，手动信任一次即可；端口可用 `.env` 中的 `HTTPS_PORT` 修改。证书持久保存在 Docker 命名卷中，重建容器不会变化。不启用该 profile 时系统与此前完全一致，不额外运行任何服务。

## 常见问题

- **BitLocker 解锁失败？** 不支持 TPM / 智能卡解锁，仅支持密码与 48 位恢复密钥；新版 BitLocker 元数据会自动改用 cryptsetup 引擎，无需手动处理。
- **写入提示只读 / 受保护？** 默认以只读模式挂载。先安全弹出，再以读写模式重新解锁挂载。
- **SFTP 连不上？** 确认客户端选的是 `SFTP`（不是 FTP）、`SFTP_HOST_PORT` 端口正确、防火墙放行；首次连接需确认主机密钥指纹。主机密钥持久保存在 `data/ssh/`，重建容器指纹不变，若客户端突然告警密钥变更，应警惕是否连错了主机。
- **连上后看不到 app / etc 等目录？** 这是正常的安全隔离：SFTP 根目录被锁定在挂载目录，只能看到已挂载的磁盘。
- **登录提示“尝试过于频繁”？** 同一来源 10 分钟内连续失败 5 次会被临时拦截，等待提示的倒计时结束后再试。
- **磁盘卡片上没有 SMART / 温度？** 部分 USB 硬盘盒不支持 SMART 透传，此时信息条自动隐藏，不影响解锁与挂载。
- **中文文件名乱码？** 挂载 FAT32 等文件系统时已统一加 `iocharset=utf8`；SFTP 协议本身使用 UTF-8，正常客户端无需额外设置。
- **两块盘显示同一份数据？** 同一硬盘盒内的多块硬盘可能上报相同序列号（USB 3.0 UAS 桥接下常见），磁盘 ID 冲突会导致挂载目录与 SFTP 路径互相覆盖；v1.0.3 起自动为冲突磁盘追加内核设备名后缀（如 `FC30383E…-sdc`）区分。

## 目录结构

```
blockusbread/
├── app/
│   ├── devices/      # lsblk/blkid 设备扫描、uevent 热插拔监听、SMART 查询
│   ├── mounts/       # dislocker / cryptsetup / mount 编排、状态机、速率与会话采样
│   ├── stores/       # 本地 / 远程存储适配、统一卷注册表
│   ├── sftp/         # sshd 配置渲染、进程守护、账号密码同步
│   ├── web/          # FastAPI 路由、会话、限流、文件浏览、SSE 事件
│   ├── static/       # 管理网页（HTML/CSS/JS + 图标）
│   └── ...           # 配置、日志、加密凭据存储、数据模型
├── deploy/caddy/     # 可选 HTTPS 反代（tls profile）的 Caddyfile
├── tests/            # pytest 单元测试
├── .github/workflows # CI：ruff + pytest + Docker 构建
├── Dockerfile
├── docker-compose.yml
├── .env.example
└── VERSION
```

## 版本记录

按[语义化版本](https://semver.org/lang/zh-CN/)命名，时间倒序；每条记录包含变更类型，只记录用户可见的变化。

### v1.1.0

**新增**

- **凭据免密解锁**：勾选「记住此卷」的 BitLocker 卷再次解锁时不再需要输入密码，面板直接显示「解锁并挂载（已记住凭据，免输密码）」按钮，一键解锁挂载，读写模式选择保留；未记住凭据的卷不受影响。
- **磁盘卡片标题显示分区卷标**：优先显示卷标（不带盘符），无卷标回退设备名（如 `sdc`）；BitLocker 卷的卷标随元数据加密、原始分区上读不到，卷解锁后自动从解密映射设备补读真实 NTFS 卷标（未解锁时仍显示设备名）。

**修改**

- **「记住此卷」改为只记住密码，不再自动挂载**：由「插入 / 重启后自动解锁挂载」变为「手动解锁时免输密码」——插入硬盘、重启软件或容器后卷只登记显示，挂载始终需要手动点击；「安全弹出」后卷保持锁定，不再自动重新挂载，重新插拔或手动解锁后才可再次使用。
- 传输任务卡的路由行改为「源文件夹 → 目标文件夹」显示（取路径最后一段，根目录回退卷名），悬停提示完整路径。

### v1.0.3

**修改**

- 传输速度计改为显示**所在硬盘的真实读 / 写吞吐**：此前按 SFTP 网络流量统计，现按块设备扇区计数差分（2 秒采样）计算，↓ 表示读取、↑ 表示写入，FUSE 挂载的分区自动回退为文件系统采样。速度计仅在任务「传输中」时显示（绿色，如 `12.5 MB/s`），排队中 / 已完成 / 失败状态不再显示。

**修复**

- 修复同一硬盘盒内多块硬盘上报相同序列号（USB 3.0 UAS 桥接下常见）时磁盘 ID 冲突，导致挂载目录与 SFTP 路径互相覆盖、两块盘显示同一份数据的问题；现自动为冲突磁盘追加内核设备名后缀（如 `FC30383E…-sdc`、`…-sdd`）。

### v1.0.2

**修改**

- 后台传输的**剩余时间估算平滑化**：由 10 秒窗口两端点差分改为每 5 秒重算一次并做指数平滑（EWMA），速率波动时剩余时间平滑收敛，不再反复大幅跳变；进度条与字节进度仍每秒刷新。

### v1.0.0

**新增**

- **本地文件存储**：在 `docker-compose.override.yml` 中把宿主机目录映射到 `/mnt/usb/local/<存储名>` 即可作为本地存储使用，始终可读写、不可弹出；多个映射合并为一张「本地文件」卡片，每个位置一行。
- **远程存储**：顶栏「挂载远程存储」通过 SFTP 把远程硬盘挂载进容器，浏览 / 上传 / 互传与外接存储一致；支持「快速连接」（粘贴 `sftp://user@host:port/path` 自动填充表单）；凭据用 `SECRET_KEY` 加密保存，重启自动重连；挂载失败稳定显示「连接失败」并提供重连 / 删除。
- **远程组**：远程组留空默认为用户名，可自定义；同组挂载合并到一张组卡片下，每个远端路径一行，类似 USB 多分区。
- **三类存储互传**：本地文件、外接存储、远程存储之间可互相移动 / 复制，目标位置按存储类型分组。
- **传输队列**：同一时间只执行一个传输任务，涉及相同源 / 目标盘的后续任务自动排队，上一任务完成后立即开始；任务卡新增剩余时间显示。
- 页面存储区域固定排布为本地存储 → 外接存储 → 远程存储，无对应存储时自动隐藏。

**修改**

- 「复制 SFTP 路径」按钮改为**点击卷信息中的 SFTP 路径条**一键复制；SFTP 连接信息条同步展示三类存储的子目录规则。
- 远程存储挂载弹窗加宽至 `min(640px, 94vw)` 并增加内边距：远端路径独占一行，远程组 / 主机 / 端口 / 用户名对称排布；移动端（≤480px）自动全屏。
- 界面主题亮度提升，三类存储卡片视觉风格统一；本地 / 远程存储更换为与整体风格一致的 SVG 图标。

**修复**

- 修复添加远程存储时请求字段错误导致 500 的问题。
- 修复挂载失败的远程存储行显示假容量条、状态不稳定的问题。

### v0.1.0

**新增**

- **网页文件浏览器**：挂载后点「浏览文件」即可在网页内逐层浏览目录、下载文件；视频 / 音频在线播放并支持拖动进度，图片直接预览。以读写模式挂载的卷还可以在网页内**上传文件**（带进度条、同名覆盖确认）、**删除**与**重命名**；只读卷不显示任何写操作。
- **容量占用显示**：每个已挂载卷显示已用 / 总量 / 可用与占用百分比条，剩余不足 10% 时变为橙色提醒。
- **SFTP 会话面板**：有客户端连接时，页面顶部显示当前连接数与登录用户，展开可查看“谁正在读取 / 写入哪个文件”；占用中安全弹出时，错误提示会直接列出占用者与文件名。
- **网页日志查看**：顶栏「日志」按钮打开日志窗口，显示最近运行日志（按级别着色、每 5 秒自动刷新、可锁定自动滚动），无需登录主机即可排查问题。
- **SMART 健康信息**：支持 SMART 的硬盘在卡片上显示健康状态、温度、通电时长与启停次数，并提供手动重新检测；USB 硬盘盒不支持透传时整块信息自动隐藏。
- **可选 HTTPS**：新增 `tls` 配置档（Caddy + 自签证书，默认关闭）。用法：`docker compose --profile tls up -d`，随后访问 `https://<宿主机IP>:8443`，浏览器首次手动信任证书即可；端口由新环境变量 `HTTPS_PORT`（默认 8443）控制。
- **自动化测试与 CI**：新增 pytest 单元测试套件与 GitHub Actions（代码检查、单元测试、Docker 构建）。

**修改**

- SSH 主机密钥改为持久保存在 `data/ssh/`：此前每次重建容器指纹都会变化、客户端反复告警，现重建容器后指纹保持不变。
- 经 HTTPS 反代访问管理页时，登录 Cookie 自动加 `Secure` 标记；管理服务统一按反代转发头识别真实协议。

**修复**

- 加固登录接口：同一来源 10 分钟内连续失败 5 次后临时拒绝登录并返回剩余等待时间，缓解密码爆破；sshd 同步收紧认证尝试次数与宽限时间。
- 保存凭据的 `data/secrets.db` 权限收紧为仅容器 root 可读写（600）。

### v0.0.3

**新增**

- 文件共享由 SMB 改为 **SFTP**（OpenSSH sshd + internal-sftp）：连接方式为 `sftp://<宿主机IP>:2222`（可用 `SFTP_HOST_PORT` 修改端口），账号密码与管理页相同，支持 WinSCP / FileZilla / VLC 等标准 SFTP 客户端。
- 每个已挂载卷在网页分区行右侧显示**实时下载 / 上传速率**（绿色 ↓ 下载、橙色 ↑ 上传，每 2 秒刷新），按各卷的 SFTP 实际传输字节统计，不受系统缓存影响。

**修改**

- 共享端口环境变量从 ~~`SMB_HOST_PORT`（默认 445）~~ 改为 `SFTP_HOST_PORT`（默认 2222），不再受宿主机 SMB 占用 445 端口的限制。
- 共享访问路径从 SMB 的 `\\<主机>\usb\<磁盘ID>\part<序号>\fs` 变为 SFTP 的 `sftp://<主机>:2222/<磁盘ID>/part<序号>/fs`。

**修复**

- 修复 SFTP 账号为 root 权限（UID 0）且未做目录锁定时，客户端连接后可浏览容器内 app / etc 等底层目录的问题；现通过 ChrootDirectory 锁定在挂载根目录，只能看到已挂载的磁盘。

**移除**

- ~~Samba（smbd）文件共享~~：实际使用中容易掉盘，按专业建议整体替换为 SFTP；同时移除镜像中的 samba / smbclient 依赖与 445 端口暴露。

### v0.0.1

**新增**

- 首个可用版本：单容器内置 FastAPI 管理后端与文件共享服务，提供网页管理（端口 8000）与局域网文件访问（早期版本为 SMB / 端口 445，自 v0.0.3 起改为 SFTP / 端口 2222）。
- BitLocker 卷支持**用户密码**与 **48 位恢复密钥**解锁；dislocker 引擎优先，遇到新版元数据格式自动切换 cryptsetup。
- 支持 NTFS / exFAT / FAT32 / ext4 普通分区直接挂载，中文文件名统一 UTF-8。
- 挂载默认**只读**；可勾选读写模式并需二次确认。
- USB 硬盘热插拔自动识别（uevent + SSE 实时刷新），拔出自动清理，支持网页「安全弹出」。
- 可选「记住此卷」：凭据用 `SECRET_KEY` 加密存入本地 SQLite，插入 / 重启后自动解锁。
- 账号密码由 `ADMIN_USER` / `ADMIN_PASSWORD` 环境变量管理，网页登录与文件共享共用一套；页面信息条可复制连接地址、账号与密码（密码隐藏显示）。
- 响应式品牌绿管理界面，适配手机等窄屏设备。
