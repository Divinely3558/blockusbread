# BlockUSBRead

在 Docker 容器中解密并挂载 BitLocker USB 硬盘，通过网页管理、用 **SFTP 与内置文件浏览器** 读取文件。

单容器内置 FastAPI 管理后端与 OpenSSH sshd（internal-sftp）：网页负责解锁 / 挂载 / 浏览 / 弹出，挂载后的卷既可在网页内直接浏览、在线播放与上传，也通过 SFTP 共享给局域网内的电脑、手机播放器直接访问，可流畅播放视频等大文件。SFTP 会话被 Chroot 锁定在挂载根目录，无法浏览容器其他路径。

- **BitLocker**：支持用户密码与 48 位恢复密钥；dislocker 引擎优先，遇到新版元数据格式自动切换 cryptsetup
- **普通分区**：NTFS / exFAT / FAT32 / ext4
- **三类存储**：本地文件（宿主机目录映射进容器，始终可读写、不可弹出）、外接存储（USB 硬盘）、远程存储（经 sshfs 把远程 SFTP 目录挂载进来，支持密码或 SSH 私钥认证、按「远程组」命名归组），三者可在网页内互相移动 / 复制文件
- **Windows 式盘符**：外接与远程挂载的卷以盘符命名（`C`~`Z`，单字母用完接 `Aa`~`Zz`），拔出重插 / 重启容器保持不变；网页显示「盘符:卷标」，同名卷标、同名远端路径自动区分；本地存储保持映射名
- **网页文件浏览**：目录浏览、视频 / 音频在线播放（支持拖动进度）、图片预览、文本在线查看、文件下载；读写卷额外支持上传、删除、重命名，并可把文件 / 文件夹在三类存储之间移动或复制，**支持勾选多项批量提交**（容器后台传输，页面底部常驻进度条显示百分比 / 剩余时间 / 当前文件并可取消；传输前自动预检目标剩余空间，放不下会直接提示）
- **默认只读**，更安全；需要写入时可勾选读写模式（二次确认）
- **实时状态**：每个已挂载卷显示所在硬盘的真实读 / 写吞吐（↓ 读取 / ↑ 写入）与容量占用条；顶栏 KPI 概览条汇总「已挂载 / 全部卷」（副行按本地 · 外接 · 远程分别计数）、全部卷合计读 / 写速率、当前 SFTP 连接数与打开中的文件数
- **三个视图 + 键盘操作**：左侧导航分为存储 / 传输 / 会话三个视图，条目带实时徽标（异常卷数、进行中任务数、活动连接数），可折叠且记住状态，`#/storage`、`#/jobs`、`#/sessions` 可直接收藏分享；表格支持 `↑/↓/Home/End` 行间移动、`Enter` 打开、`E` 弹出、`Esc` 逐层关闭，`d`/`j`/`s` 切视图、`r` 刷新设备（详见[界面导航与快捷键](#界面导航与快捷键)）
- **整盘弹出**：外接磁盘标题行可一次「弹出整块硬盘」，卸载该盘全部已挂载分区
- **可观测性**：支持 SMART 的硬盘显示健康状态、温度与通电时长
- **安全加固**：SSH 主机密钥持久化（指纹不变）、登录失败限流、经可选 HTTPS 反代访问时自动下发 Secure Cookie
- **热插拔**：插入自动识别、拔出自动清理，网页实时刷新（SSE），无变化时不刷新
- **记住此卷**（需配置 `SECRET_KEY`）：凭据加密后存入本地，手动解锁时免输密码（不自动挂载），也可随时「忘记凭据」改回手动输入
- **单端口管理 + SFTP 共享**：管理页 `8000`，SFTP 默认 `2222`（可改）；可选 HTTPS 入口 `8443`
- 移动友好的响应式网页界面：手机竖屏 / 横屏、平板、桌面各有一套版式（手机为底部导航 + 卡片式卷列表），详见[界面导航与快捷键](#界面导航与快捷键)

> 当前版本 **v26.11.22a**。不支持 TPM 解锁、空闲自动锁定与多用户；HTTPS 为可选自签证书方案（见[文末](#可选-https局域网加密访问)）。

## 环境要求

- 已安装 Docker 与 Docker Compose（`docker compose` 插件）的 Linux 主机
- 容器以 `privileged` 运行并挂载 `/dev`，用于读取块设备、执行 mount 与 FUSE 挂载

## 快速开始

```bash
# 1. 进入项目目录
cd blockusbread

# 2. 创建环境配置文件
cp .env.example .env
# 编辑 .env：
#   ADMIN_PASSWORD=你的强密码
#   SECRET_KEY=$(openssl rand -base64 32)   # “记住此卷”加密密钥，必填

# 3. 构建并后台启动
docker compose up -d --build
```

启动后浏览器打开 `http://<宿主机IP>:8000`，用 `.env` 中的 `ADMIN_USER`（默认 `admin`）与 `ADMIN_PASSWORD` 登录。

常用命令：

```bash
docker compose logs -f          # 查看实时日志
docker compose restart          # 重启
docker compose down             # 停止（停止时自动卸载全部卷）
```

## 环境变量

在 `.env` 中配置：

| 变量             | 必填   | 默认    | 说明                                                                                                         |
| ---------------- | ------ | ------- | ------------------------------------------------------------------------------------------------------------ |
| `ADMIN_USER`     | 否     | `admin` | 管理员账号，网页登录与 SFTP 共用                                                                             |
| `ADMIN_PASSWORD` | **是** | —       | 管理员密码，网页与 SFTP 共用。修改后执行 `docker compose up -d` 重建容器即生效                               |
| `SECRET_KEY`     | **是** | —       | “记住此卷”与远程存储凭据的加密密钥，`openssl rand -base64 32` 生成。**一旦使用请勿更换**，否则已保存凭据无法解密 |
| `LOG_LEVEL`      | 否     | `INFO`  | 日志级别，`DEBUG` / `INFO` / `WARNING` / `ERROR`（填其他值按 `INFO` 处理）                                   |
| `SFTP_HOST_PORT` | 否     | `2222`  | SFTP 映射到宿主机的端口（容器内固定监听 22）。端口被占用时改为其他值                                         |
| `HTTPS_PORT`     | 否     | `8443`  | 可选 HTTPS 反代端口；需以 `--profile tls` 启动 Caddy 反代才生效，详见[可选 HTTPS](#可选-https局域网加密访问) |

> 账号密码以容器环境变量为唯一来源，不提供网页改密入口。改密码：编辑 `.env` 后 `docker compose up -d`。
>
> 缺 `SECRET_KEY` 时容器无法启动（compose 强校验）；若绕过 compose 直接运行，管理页会显示「未配置 SECRET_KEY」警告条，「记住此卷」与远程存储功能隐藏，一次性密码解锁外接盘仍可用。另有 `MOUNT_ROOT`（`/mnt/usb`）、`WORK_ROOT`（`/mnt/.vols`，BitLocker 解密中间层）、`DATA_DIR`（`/app/data`）、`SFTP_PORT`（容器内 22）四个内部路径 / 端口变量，默认值与 Dockerfile 约定绑定，正常部署无需修改。

## 使用流程

1. 将 USB 硬盘插入宿主机，外接存储区会自动出现该盘（无需刷新）；支持 SMART 的硬盘会在磁盘标题行显示健康、温度与通电信息（硬盘盒不支持透传时自动隐藏）。
2. BitLocker 卷：选择「用户密码」或「恢复密钥」，输入后点「解锁并挂载」。
   - 默认只读；勾选「以读写模式挂载」会弹出二次确认。
   - 勾选「记住此卷」（需配置 `SECRET_KEY`）后凭据加密保存：下次解锁无需再输密码，直接点「解锁并挂载」即可；已记住凭据的卷**不会自动挂载**，插入 / 重启后仍需手动点击解锁。想改用其他密码或恢复密钥时，点「忘记凭据，重新输入密码」清除已保存凭据，面板会切回输入框。
3. 普通分区（NTFS / exFAT / FAT32 / ext4）可直接挂载。
4. 挂载成功后，该卷一行显示盘符与卷标（如 `D:BACKUP`）、文件系统、容量条、所在硬盘的实时读 / 写吞吐与「浏览」按钮；点盘符单元格可复制该卷的 SFTP 路径，也可以通过 [SFTP](#访问-sftp) 访问文件。
5. 有人正在通过 SFTP 传输时，顶栏 KPI 条的「SFTP 连接」与左侧「会话」视图会显示“谁正在读取 / 写入哪个文件”（含每个文件所在卷与操作用户）；弹出被占用的卷时，错误提示会直接列出占用文件，并附「查看占用」链接跳转过去。空闲连接不阻止弹出。
6. 用完先在各客户端断开连接，再到网页点「弹出」（外接磁盘标题行还有「弹出整块硬盘」，一次卸载该盘全部分区）；直接物理拔出也会自动清理挂载状态。涉及某块硬盘的传输任务未完成时，弹出该盘上的卷会被拒绝，等任务结束即可。

不接 USB 盘也可以用：通过[三类存储](#三类存储)把宿主机目录或远程 SFTP 硬盘接入，网页与 SFTP 的使用方式与外接硬盘完全一致。

## 三类存储

存储视图按**本地存储 → 外接存储 → 远程存储**三个分组从上到下排布（分组行显示「N 个位置 / 台设备 / 个挂载」汇总），没有对应存储的分组自动隐藏；外接存储下每台硬盘是一个标题行（型号、SN、接口、容量与 SMART 信息，多分区各占一行）。三类存储之间可在网页内互相移动 / 复制文件。

**本地文件**（始终可读写、不可弹出）：编辑 `docker-compose.override.yml`（已被 `.gitignore` 忽略，不进仓库），把宿主机目录 bind 映射到 SFTP 根目录 `/mnt/usb/<存储名>`：

```yaml
services:
  blockusbread:
    volumes:
      - /home/你的用户/资料:/mnt/usb/资料
      - /home/你的用户/照片:/mnt/usb/照片
```

支持多个映射：多个位置都归入「本地存储」分组，每个位置一行；修改后 `docker compose up -d` 重建容器生效。

**远程存储**（SFTP 挂载远程硬盘）：点左侧导航底部的「**远程**」（悬停提示「挂载远程 SFTP 存储」；需配置 `SECRET_KEY`，凭据加密后才落盘，未配置时按钮隐藏），无存储时的空状态页也有同一入口。支持两种填法：

- **快速连接**：粘贴 `sftp://user@host:port/path`（或 `sftp://host:port/path`）自动填充下方字段，只需再输入凭据；
- **逐项填写**：主机、端口、用户名、远端路径，认证方式在「密码认证 / SSH 私钥」之间切换——密码认证填 SSH 密码，私钥认证粘贴 OpenSSH PEM 私钥（`-----BEGIN OPENSSH PRIVATE KEY-----`，适用于只接受密钥的 NAS / 远程主机）。

「远程组」留空默认为用户名，可自定义；它作为该挂载的显示名前缀（卷名形如 `nas:/media`），同一远程组下多台主机 / 多个路径的挂载排在一起，每行一个挂载，行内副标题显示 `主机:远端路径`；同名远程组下重复添加相同「主机 + 端口 + 路径」会被拒绝。凭据使用 `SECRET_KEY` 加密保存到容器数据目录，重启容器自动重连；连接失败时该行稳定显示「连接失败」，可重新连接或删除，删除仅移除挂载配置、不动远端文件。

## 网页浏览文件

挂载任意卷后，在该卷一行点击「**浏览**」即可从右侧滑出文件浏览抽屉，无需另装 SFTP 客户端：

- **浏览与下载**：面包屑逐层进入目录，点击文件夹行进入、点击文件行按类型预览（无法预览的类型直接下载）；每行的下载按钮随时可显式下载。
- **在线播放 / 预览**：视频、音频在弹窗内直接播放，支持拖动进度（HTTP Range）；图片直接预览。抽屉顶部有刷新按钮。
- **上传**（仅读写卷）：点「上传文件」选择本地文件，一次一个，带进度条；同名文件会先询问是否覆盖。
- **删除 / 重命名**（仅读写卷）：每行右侧操作按钮，均有二次确认；删除文件夹会连同其内容一并删除（确认文案已明示），不可恢复。
- **在线查看文本**：txt / log / json / md / yaml / csv 及常见代码、配置等 40 余种纯文本类型（1 MiB 以内）点击直接在弹窗内查看，弹窗同时显示文件大小与识别到的编码（UTF-8 解码失败时自动回退 GB18030，中文 Windows 生成的 ANSI 文本不乱码）；内容按纯文本渲染，盘内的 HTML / 脚本不会执行；超过大小限制请下载后用编辑器打开。
- **移动 / 复制到其他卷**：可在列表里**勾选多个文件 / 文件夹**，用顶部操作条的「复制到…」/「移动到…」一次批量提交；也可对单行点右侧传输按钮（读写卷为「移动」，只读卷为「复制」），弹窗分两步：① 选目标硬盘（下拉按本地 / 外接 / 远程存储分组，只列出可写入的存储）② 选目标文件夹（面包屑 + 目录列表逐层进入）。读写源可勾选「保留源文件」把移动改成复制，只读源固定为复制并给出提示。开始传输前自动预检目标卷剩余空间，待传内容放不下时直接提示、不创建任务。任务在容器后台执行，关闭网页也会继续；同一时间只执行一个任务，涉及相同磁盘的后续任务自动排队，前一任务完成后立即开始。页面底部的常驻进度条与左侧「传输」视图（可按 全部 / 进行中 / 已结束 筛选）可查看排队状态与实时进度（百分比、已传大小、剩余时间、当前文件）并随时取消；移动被取消或失败时自动删除目标盘半成品，源文件保持不动。
- 只读卷只提供浏览 / 下载 / 播放，所有写操作按钮不显示。

> 浏览器内置播放器对编码有要求：H.264/AAC 的 MP4 兼容性最好；MKV、HEVC 等若无法播放，请改用 VLC 经 SFTP 访问。

## 访问 SFTP

SFTP 登录后根目录即挂载目录（容器内 `/mnt/usb`，已做 Chroot 隔离，看不到容器底层文件）。所有已挂载的卷直接出现在根目录下，以 **Windows 风格盘符命名**：外接卷与远程挂载依次分配 `C`~`Z`（单字母用完接 `Aa`~`Zz`，共 700 个，用尽拒绝挂载），盘符按卷记忆，拔出重插 / 重启容器不变，同名卷标、同名远端路径自动区分；本地存储以映射时的存储名命名（不参与盘符）。~~此前以卷标命名（无卷标回退盘 ID，重名自动追加 `-2`、`-3` 后缀），现已被盘符取代。~~ 网页各卷行显示「盘符:卷标」（如 `D:BACKUP`）方便对应；未挂载的卷不显示。
账号密码与网页登录相同；页面顶部信息条可一键复制连接地址与账号，**密码不下发也不显示**——它就是你登录管理页用的那个口令，客户端里直接填（早期版本曾把明文口令随 `/api/share` 下发并放进复制按钮，已移除：响应会进浏览器历史与代理日志，DOM 里的明文任何扩展都能读走）。要复制某个卷的完整 SFTP 路径，点该卷一行的**盘符单元格**（`D:` 那个按钮），或点行末「⋯」→「复制 SFTP 路径」。

**图形客户端（推荐）**：WinSCP、FileZilla、Cyberduck 等

- 协议：`SFTP`，主机：`<宿主机IP>`，端口：`2222`（改过则用新端口）
- 登录后根目录下的各个文件夹即为已挂载的卷

**命令行**

```bash
# 交互式登录后用 cd / ls / get / put 操作
sftp -P 2222 admin@<宿主机IP>

# 直接下载 / 上传单个文件（目录名即网页上显示的盘符，本地存储为存储名）
scp -P 2222 admin@<宿主机IP>:'D/视频.mp4' ./
scp -P 2222 ./视频.mp4 admin@<宿主机IP>:'D/'
```

Linux 图形文件管理器（Nautilus / Dolphin 等）地址栏：`sftp://admin@<宿主机IP>:2222/`

**macOS**：Finder → 前往 → 连接服务器，输入 `sftp://admin@<宿主机IP>:2222`（macOS 访达对 SFTP 写入支持有限，建议用 Cyberduck / FileZilla）

**手机 / VLC 等播放器**：新建 SFTP 连接，主机 `<宿主机IP>`、端口 `2222`、用户名 `admin`，进入对应卷的目录播放

> 说明：SFTP 仅允许文件传输，禁止交互式 Shell 登录与端口转发。

## 界面导航与快捷键

管理页为暗色单页界面，登录后是「顶栏 + 左侧导航 + 内容区」三块：

- **左侧导航**：**存储**（三类存储分组表格）、**传输**（后台任务列表）、**会话**（当前 SFTP 连接与打开中的文件）三个视图，条目右侧的实时徽标分别显示异常卷数、未结束的传输任务数、活动 SFTP 连接数；底部为「远程」（挂载远程 SFTP 存储）、「折叠导航」「退出」。折叠状态记在浏览器本地，下次打开保持。
- **顶栏**：当前视图标题、「刷新设备」按钮，以及**数据新鲜度指示**——正常显示「最近更新 HH:MM:SS」，SSE 连接断开时变灰显示「实时连接已断开 · 自动重连中」，此时数据可能不是最新。
- **KPI 概览条**（存储视图顶部）：「已挂载 / 全部卷」计数（副行按本地 · 外接 · 远程分别给出数量）、全部卷合计读取 / 写入速率、SFTP 连接数与打开中的文件数；存在异常卷时整条转为警示色。各卷容量只在所属行上显示，不做汇总：容器把宿主目录 bind 进来了同一个文件系统，多个卷相加会把同一块盘重复计数。
- **深链接**：三个视图分别对应 `#/storage`、`#/jobs`、`#/sessions`，可直接收藏、分享或前进后退切换。
- **实时刷新**：设备插拔、挂载状态、任务进度通过 SSE 推送，无需手动刷新；数据没有变化时不重绘，输入到一半的密码与勾选状态也不会被重绘清掉。
- **手机 / 平板**：宽度 ≤768px，或横屏手机（高度 ≤480px 且触屏）时切换为手机版式 —— 导航移到屏幕底部（存储 / 传输 / 会话 / 远程 / 退出，文字标签常驻，折叠状态在手机上不再隐藏文字），顶栏只留标题与刷新，KPI 排成 2×2，SFTP 说明的长段文字折进「怎么用」，文件抽屉与对话框改为整屏，底部常驻传输条让开导航与安全区（iPhone 手势条不会压住按钮）。手机与平板上输入框固定 16px（iOS 小于 16px 聚焦会连整页一起放大），按钮有效热区 ≥44×44。接了实体键盘时快捷键同样可用。

键盘操作（在输入框内打字不会误触发；抽屉 / 弹窗打开时全局快捷键暂停，只保留 `Esc` 逐层关闭）：

| 按键                   | 作用                                                             |
| ---------------------- | ---------------------------------------------------------------- |
| `d` / `j` / `s`        | 切换到 存储 / 传输 / 会话 视图                                   |
| `r`                    | 刷新设备列表（等同点顶栏「刷新设备」）                           |
| `↑` `↓` `Home` `End`   | 在存储表格的卷行之间移动焦点                                     |

## 可选 HTTPS（局域网加密访问）

默认管理页为明文 HTTP，适合可信局域网。需要加密（例如在不可信网络中访问）时，可启用内置的 Caddy 反向代理，使用**自签证书**提供 HTTPS（无需域名、不依赖外部 CA）：

```bash
docker compose --profile tls up -d
```

然后访问 `https://<宿主机IP>:8443` 。浏览器首次会提示“证书不受信任”，手动信任一次即可；端口可用 `.env` 中的 `HTTPS_PORT` 修改。证书持久保存在 Docker 命名卷中，重建容器不会变化。不启用该 profile 时系统与此前完全一致，不额外运行任何服务。

## 常见问题

- **BitLocker 解锁失败？** 不支持 TPM / 智能卡解锁，仅支持密码与 48 位恢复密钥；新版 BitLocker 元数据会自动改用 cryptsetup 引擎，无需手动处理。
- **写入提示只读 / 受保护？** 默认以只读模式挂载。先弹出，再以读写模式重新解锁挂载。
- **点「弹出」被拒绝？** 该卷上有未结束的传输任务（作为源或目标都算），等任务完成（或先在「传输」视图取消）再弹；「弹出整块硬盘」会先逐个检查该盘全部分区，任一分区还在传就整体拒绝、不会只弹掉一半。
- **找不到导航底部的「远程」按钮，或解锁面板没有「记住此卷」？** 未配置 `SECRET_KEY`——页面顶部会有「未配置 SECRET_KEY」警告条，两类需要保存凭据的功能都会隐藏；设置后重启服务即可。
- **远程存储显示「连接失败」？** 多为远端不可达、凭据错误或私钥格式不对（需 OpenSSH PEM 文本）；远端路径必须以 `/` 开头。连上之后 sshfs 自带重连与保活（15 秒心跳 × 3 次），网络抖动会短暂报错、恢复后自动回到「已挂载」；「重新连接」按已保存配置重挂，「删除挂载配置」只移除本机记录与盘符，不动远端文件。
- **远程主机突然拒连并提示指纹变更？** 远端主机密钥与首次记录（`data/ssh/known_hosts_remote`，`accept-new` 策略）不一致时 sshfs 会拒绝连接——这是防中间人，请先确认远端确实重装 / 换过密钥，再清理该文件重连。
- **SFTP 连不上？** 确认客户端选的是 `SFTP`（不是 FTP）、`SFTP_HOST_PORT` 端口正确、防火墙放行；首次连接需确认主机密钥指纹。主机密钥持久保存在 `data/ssh/`，重建容器指纹不变，若客户端突然告警密钥变更，应警惕是否连错了主机。
- **连上后看不到 app / etc 等目录？** 这是正常的安全隔离：SFTP 根目录被锁定在挂载目录，只能看到已挂载的磁盘。
- **登录提示“尝试过于频繁”？** 同一来源 10 分钟内连续失败 5 次会被临时拦截，等待提示的倒计时结束后再试。
- **磁盘标题行上没有 SMART / 温度？** 部分 USB 硬盘盒不支持 SMART 透传，此时信息条自动隐藏，不影响解锁与挂载；点信息条末尾的刷新图标可重新查询。
- **中文文件名乱码？** 挂载 FAT32 等文件系统时已统一加 `iocharset=utf8`；SFTP 协议本身使用 UTF-8，正常客户端无需额外设置。卷标为 GBK 中文也能正常显示（设备扫描按 UTF-8 → GBK 逐级兼容解码）。
- **两块盘显示同一份数据？** 同一硬盘盒内的多块硬盘可能上报相同序列号（USB 3.0 UAS 桥接下常见），磁盘 ID 冲突会导致挂载目录与 SFTP 路径互相覆盖；v1.0.3 起自动为冲突磁盘追加内核设备名后缀（如 `FC30383E…-sdc`）区分。
- **网页显示的数据是不是实时的？** 状态通过 SSE 推送，顶栏新鲜度指示正常时（「最近更新 …」）无需手动刷新；显示「实时连接已断开 · 自动重连中」时才需要点「刷新设备」或检查容器是否重启。

├── .github/workflows # CI：ruff + pytest + Docker 构建
├── Dockerfile        # 单镜像：Python 后端 + sshd + dislocker / cryptsetup / ntfs-3g / sshfs

## 开发与测试

无需 Docker 即可跑单元测（Python 3.13，用 [uv](https://docs.astral.sh/uv/) 管理）：

```bash
uv sync --dev            # 安装依赖 + 开发依赖（pytest / ruff）
uv run ruff check .      # 代码检查（line-length 100，规则 E / F / I）
uv run pytest            # 单元测试
```

- pytest 固定 `--basetemp=.pytest-tmp`：传输相关用例会造大文件，跟随 `TMPDIR` 时可能撑爆小的 tmpfs 导致测试卡死；占空间就 `rm -rf .pytest-tmp`。
- CI（`.github/workflows/ci.yml`）跑的就是这三步 + Docker 构建，提交前本地跑一遍可以省一轮往返。
- 应用启动时会拉起 sshd（渲染 `/etc/ssh/sshd_config`、把 `/mnt/usb` 改属主为 root），因此**不建议在宿主机直接 `uv run uvicorn app.main:app` 调试**——那需要 root 且会动宿主机自己的 SSH 服务配置。改前端 / 接口逻辑时，用 `docker compose up -d --build` 在容器里验证更稳；纯逻辑（设备扫描、盘符、限流、传输队列）走单元测试即可。
- **版本号**：按日期版本命名 `vYY.MM.DD[x]`（如 `v26.11.22a`，`a` 表示当日第 1 版，同日再发版依次 `b`、`c`…，换天重新从 `a` 开始）。`VERSION` 是唯一来源（`app/__init__.py` 读取，`/health` 与网页顶栏、登录页显示），`pyproject.toml` 与 `uv.lock` 的 `version` 需手工同步；发布时三处一起改，并在 README「版本记录」补一条。

- 修复卷标 / 硬盘型号含 **GBK 编码中文**（Windows 中文环境常见）时 `lsblk` 输出无法按 UTF-8 解码、导致设备扫描整体失败、磁盘列表不出现的问题；现按 UTF-8 → GBK → 替换非法字符三级兼容解码，中文卷标可正常显示。

### v0.0.1

**新增**

- 首个可用版本：单容器内置 FastAPI 管理后端与文件共享服务，提供网页管理（端口 8000）与局域网文件访问（早期版本为 SMB / 端口 445，自 v0.0.3 起改为 SFTP / 端口 2222）。
- BitLocker 卷支持**用户密码**与 **48 位恢复密钥**解锁；dislocker 引擎优先，遇到新版元数据格式自动切换 cryptsetup。
- 支持 NTFS / exFAT / FAT32 / ext4 普通分区直接挂载，中文文件名统一 UTF-8。
- 挂载默认**只读**；可勾选读写模式并需二次确认。
- USB 硬盘热插拔自动识别（uevent + SSE 实时刷新），拔出自动清理，支持网页「安全弹出」。
- 可选「记住此卷」：凭据用 `SECRET_KEY` 加密存入本地 SQLite，插入 / 重启后自动解锁。
- 账号密码由 `ADMIN_USER` / `ADMIN_PASSWORD` 环境变量管理，网页登录与文件共享共用一套；页面信息条可复制连接地址、账号与密码（密码隐藏显示）。
- 响应式品牌绿管理界面，适配手机等窄屏设备。
